Using SEXP and cpp conversions

as_sexp() allows to pass objects from Armadillo to R while as_cpp<> allows to pass objects from R to Armadillo. as_sexp() allows to convert mat to doubles_matrix<> and imat to integers_matrix<>. as_cpp<> allows to convert doubles_matrix<> to mat and integers_matrix<> to mat.

The following functions illustrate this:

[[cpp4r::register]] SEXP implicit_conversion_double(SEXP x) {
  mat y = as_cpp<mat>(x);
  return as_sexp(y);
}

[[cpp4r::register]] SEXP implicit_conversion_int(SEXP x) {
  imat y = as_cpp<imat>(x);
  return as_sexp(y);
}

Both of these would work if we pass a matrix \(M\) defined in any of the following ways:

M <- matrix(1:4, nrow = 4, ncol = 4)
storage.mode(M)
# > [1] "integer"

implicit_conversion_double(M)

storage.mode(M) <- "double"
implicit_conversion_int(M)

It is similar for other Armadillo types, such as fmat, imat and umat with both as_sexp() and as_cpp<>.

Besides SEXP conversions, armadillo4r enforces strict types when using doubles_matrix<> and integers_matrix<>. For example, the following function would only work if we pass a matrix of doubles to it:

[[cpp4r::register]] doubles_matrix<> strict_conversion_double(doubles_matrix<> x) {
  mat y = as_mat(x);
  return as_doubles_matrix(y);
}

Otherwise, when passing a matrix of integers to it, we would get an error:

Error: Invalid input type, expected 'double' actual 'integer'
